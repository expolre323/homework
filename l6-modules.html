模块 Modules

物理功能如何实现？
每个子系统由"感知模块 + 控制模块 + 执行模块 + 通信/电源模块"构成，模块级需求可量化、可验证。
所属子系统模块功能关键要求（示例）
线控转向 SbW转向执行电机模块输出转向力矩双三相绕组，单绕组 50% 力矩降级运行
转角/力矩传感模块方向盘与轮端转角测量双通道冗余，分辨率 ≤ 0.1°，采样 ≥ 1 kHz
路感模拟模块生成驾驶员路感力矩力矩梯度可标定，延迟 ≤ 5 ms
转向 ECU 模块转向闭环控制双 MCU 锁步核（ASIL-D），10 kHz 电流环
线控制动 BBWEMB 卡钳执行模块轮端夹紧力输出力控精度 ±1%，失电可机械释放
压力/位移传感模块压力与活塞位移测量双传感器交叉验证，故障误报率 < 10 ppm
制动控制 ECU 模块压力闭环 + ABS/ESC 融合150 ms 内建压，支持 AEB 预填充直通
线控驱动 DBW驱动电机 + MCU 模块轮端扭矩输出峰值扭矩精度 ±2%，响应 ≤ 10 ms
扭矩监控模块独立校核扭矩指令与控制通道异构芯片，超差即断高压
线控换挡 ShBW换挡执行器模块驻车锁止/挡位状态切换P 挡自锁，断电保持驻车
挡位反馈模块实际挡位检测双霍尔冗余，硬线信号备份
线控悬架CDC/主动作动器模块阻尼/垂向力调节响应 ≤ 20 ms；主动式含储能源
高度/加速度传感模块车身姿态测量四角高度 + 三轴 IMU，同步采样
电源与通信骨干冗余电源模块双路低压供电与切换任一路失效无扰切换（< 2 ms）
网关/TSN 通信模块域间报文路由与时间同步CAN-FD + 车载以太网，报文端到端保护（E2E）
底盘域控制器模块运动分解与仲裁主控ASIL-D，双锁步 MCU 异构冗余
数据记录模块控制指令与状态记录（EDR）满足监管追溯，掉电保存

模块 → 子系统 → 平台的验证闭环

  • 模块级：单体验证（精度、时延、冗余切换）→ 台架 HIL 测试
  • 子系统级：执行器闭环性能 + 故障注入验证
  • 平台级：整车运动控制指标（横摆跟踪、端到端时延）验收
